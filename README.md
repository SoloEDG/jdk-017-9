# ORBIT

小行星全景工作台，含「星球创作」与「印刷版面」两种模式。

安装：`npm install`

本地启动：`npm run dev`

检查：`npm run typecheck`，`npm run build`，`npm run test:print`。

Docker 启动：`docker compose up --build`，打开 http://localhost:8517 。

## 印刷版面

顶栏切换到「印刷版面」，把当前星球作品排到实体卡片或纸张上。

- **物理尺寸**：纸张按毫米设置（A4/A3/A5/明信片/方卡或自定义），可切换纵横向、单页或跨页。
- **出血、安全区、裁切线**：出血、安全区都是毫米值；裁切线画在出血之外、MediaBox 之内。跨页有折标与装订线。
- **图框**：圆形或矩形（可设圆角），位置与尺寸以毫米保存。同一构图可被多个图框引用，每个图框单独保存取景平移与缩放。
- **构图编辑**：构图被多个图框引用时，修改前会先列出全部受影响图框，确认后才进入编辑；取景与位置不受影响。
- **屏幕缩放**：只改变 `ppmm`（每毫米屏幕像素），裁切线、出血、折线、安全区与跨页位置都由毫米几何推导，缩放时不动。
- **输出**：打印分辨率按成品毫米折算像素，与屏幕无关。导出 PDF 可选「含出血」「成品」「双页」；双页会输出带出血页与成品页两页，轮廓完全一致。裁切线、折标、安全区参考线与文字都是矢量，不随整页栅格化。

### 栅格化策略

作品只按**构图**栅格化：一个构图按它所有引用图框中最大物理需求渲一次共享位图，再由各图框从该位图裁切取景。不同图框、不同出血变体都不会重复渲染同一作品，分辨率也不会因页面元素增多而成倍膨胀。单构图默认上限 4096 px，总栅格预算 256 MB，触顶时降分辨率并在导出面板提示；裁切线与文字仍保持矢量。

预览用同一份毫米几何，异步分条渲制栅格；导出与预览使用同一套边界计算，安全区越界在两边都落在同一物理位置，可核对。

## 测试

`npm run test:print` 运行印刷几何与导出的回归测试。导出测试需要可选的 `@napi-rs/canvas`（仅在 Node 中模拟 canvas），未安装时会自动跳过。
